Pin&Roll

Two extra buttons in the title bar of your windows: keep a window on top, or roll it up to its title bar.

The two buttons

ButtonWhat it does
Push-pin Keeps the window above all other windows. Click again to release it. The pin is hollow when off and solid when on, and always shows the window's real state, also when another tool pinned it.
Roll-up Shrinks the window to its title bar so you can see what is behind it. Click again to roll it back down. A rolled-up window keeps its place and width and can still be dragged.
  • Left-click a button to use it. It also works on windows that are not active.
  • Right-click a button for Customize <program>..., Settings... and this help.
  • The buttons hide while you drag a window and come back when you let go.
  • Maximizing a rolled-up window shows it in full; restoring it brings the strip back.
  • Resizing a rolled-up window by its top or bottom edge ends the rolled state.
  • Exiting Pin&Roll, or switching the roll-up button off, unrolls every window.

The icon in the notification area

Pin&Roll has no main window. It sits as a blue pin icon near the clock (possibly under the ^ arrow).

  • Double-click the icon to open the settings.
  • Click it for the menu: the three main switches, Settings..., Save diagnostics..., Help, About, More from this developer, Check for updates and Exit.

Settings

Every change shows on your windows immediately, so you can position the buttons by eye. OK saves, Cancel puts everything back.

All programs

Push-pin button / Roll-up button
Show or hide each button everywhere.
When rolled up, keep the window bar on top
A rolled-up strip stays above other windows until you unroll it.
Peek
Rest the mouse on the roll-up button of a rolled-up window for about half a second and the window opens. It stays open while the mouse is on the title bar and rolls up again as soon as it leaves. Clicking the roll-up button while it is open keeps it open. Off by default.
Move the buttons left by ... pixels, and by ... more if a window is maximized
A nudge for all programs. Negative numbers move the buttons right.
Button size
Size of the buttons in percent, from 40 to 300.
Hot keys for the active window
Click a field and press a combination with Ctrl or Alt, for example Ctrl+Alt+T. Press Backspace in the field to clear it.
Start with Windows
Starts Pin&Roll when you sign in.
Check for a new version once a week
Off by default. When on, Pin&Roll asks github.com once a week whether a newer release exists and shows a notification if so; click it to open the download page. Nothing is downloaded or installed automatically. Check for updates in the tray menu does the same on demand. These checks are the only time Pin&Roll uses the internet; GitHub sees your internet address, as with any web page you visit.
Run as administrator
Windows does not let a normal program control windows of programs that run as administrator, such as Task Manager, so those get no buttons. With this option Pin&Roll restarts with administrator rights (Windows asks once) and they get buttons too. Together with Start with Windows you are not asked again at each sign-in.

Individual programs

Some programs draw their own title bar and have their own controls where the buttons would go. Give such a program its own settings:

  • right-click one of its Pin&Roll buttons and choose Customize <program>..., or
  • click Pick an app... and choose it from the running programs.

Select a program in the list to edit it. Remove deletes its settings.

Button position
Right: next to the window's own minimize / maximize / close buttons. Left: at the left end of the title bar.
Shift left by ... pixels
Moves the buttons sideways; negative numbers move them right. Use the small arrows to nudge. At the left end a negative number (it starts at -40) moves the buttons clear of the window's icon. Once a shift or Left is set, Pin&Roll stops searching for free space in that program by itself, so the number means exactly what it says.
Shift down by ... pixels
Moves the buttons down; negative numbers move them up.
Button size
A size just for this program. 0 means the size set under All programs.
Rolled-up height
How tall the rolled-up strip is. 0 lets Pin&Roll work it out; set a number if a program's title bar is cut off or too much is left showing.

Tips

  • Tabbed title bars (Notepad, browsers): if the buttons cover a control such as the new-tab +, give the program a smaller button size (65-75%) or shift the buttons.
  • Crowded title bars: try Left end of the title bar, or keep only one of the two buttons.
  • Glyph colour: Pin&Roll draws black on light title bars and white on dark ones. After a theme change it can take a few seconds to follow.

Good to know

  • Full-screen windows get no buttons.
  • If Pin&Roll is closed unexpectedly, rolled-up windows stay rolled. Start Pin&Roll again and one click on the roll-up button restores them.
  • Settings are stored in %APPDATA%\PinRoll\pinroll.ini. Open .ini file in the settings window opens it in Notepad. You can edit it by hand and add your own comment lines (starting with a semicolon); changes are picked up a couple of seconds after you save.
  • Save diagnostics... writes a short text report about how each window's title bar was measured. It contains program names and positions, no window titles. It is useful when reporting a placement problem.
  • Pin&Roll changes nothing inside other programs: it only draws its two buttons on top of their title bars.
